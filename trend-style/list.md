# 주요 UI/UX 디자인 스타일 15선

| 번호 | 디자인 스타일 | 핵심 특징 | 느껴지는 분위기 / 느낌 |
|---|---|---|---|
| 1 | 스키우오모피즘 (Skeuomorphism) | 현실 질감(가죽, 나무, 금속 등)과 그림자를 그대로 모사 | 직관적, 아날로그, 클래식 |
| 2 | 플랫 디자인 (Flat Design) | 입체감·그림자를 완전히 뺀 2D 평면과 단순한 원색 사용 | 미니멀, 깔끔함, 가벼움 |
| 3 | 머티리얼 디자인 (Material Design) | 구글의 디자인 시스템. 종이의 겹침과 가벼운 그림자로 높낮이 표현 | 체계적, 표준적, 실용적 |
| 4 | 글래스모피즘 (Glassmorphism) | 반투명한 불투명 유리, 배경 블러(Blur), 선명한 흰색 테두리 | 미래지향적, 세련됨, 고급스러움 |
| 5 | 뉴모피즘 (Neumorphism) | 바탕색과 같은 색상의 요소에 부드러운 안팎 그림자로 입체감 표현 | 촉각적, 부드러움, 은은함 |
| 6 | 네오브루탈리즘 (Neobrutalism) | 강렬한 원색, 두꺼운 검은 테두리, 의도적인 규칙 파괴와 솔직함 | 트렌디, 파격적, 키치함 |
| 7 | 클레이모피즘 (Claymorphism) | 점토(Clay)처럼 둥글고 통통한 3D 느낌과 부드러운 내부 그림자 | 귀여움, 친근함, 입체적 |
| 8 | 아우로라 / 오로라 UI (Aurora UI) | 배경에 부드럽게 번지는 오로라 같은 비대면 그래디언트와 빛 효과 | 몽환적, 감성적, 현대적 |
| 9 | 다크 모드 UI (Dark Mode / High Contrast) | 완전한 검은색이나 어두운 회색 배경을 기본으로 한 고대비 디자인 | 눈의 피로 감소, 몰입감, 묵직함 |
| 10 | 브루탈리즘 (Brutalism) | 원형 브루탈리즘 건축처럼 정제되지 않은 날것 그대로의 웹 디자인 | 날것, 거침, 실험적 |
| 11 | 키네틱 / 미니멀 타이포그래피 | 화려한 그래픽을 줄이고 거대한 글자(Font)와 움직임에 집중 | 강렬함, 메시지 중심, 모던 |
| 12 | 90년대 / 레트로 UI (Retro / Pixel Art) | 픽셀 아트, 윈도우 95 감성의 창, 옛 컴퓨터 시스템 스타일 | 복고풍, Y2K, 유쾌함 |
| 13 | 아이소스메트릭 UI (Isometric) | 45도 사선 각도에서 내려다보는 정교한 3D 뷰 그래픽 활용 | 공간감, 정보 집약적, 정교함 |
| 14 | 유기적 / 바이오모픽 (Biomorphic / Organic) | 기하학적 도형 대신 자연스러운 곡선, 액체, 세포 형태 활용 | 자연스러움, 편안함, 유연함 |
| 15 | 미크로 인터랙션 중심 UI | 거대한 스타일 변경보다는 미세한 애니메이션과 반응에 집중 | 섬세함, 생동감, 완성도 높은 |
