# CLI 호출 기록과 시각 검수

CLI 호출이 끝나면 실제 반환한 결과와 제공한 이미지를 한 기록에 저장한다. 입력 명령·시간·종료 코드·task ID도 함께 보관한다.

## 사람이 보는 내용

브라우저의 최근 AI 호출은 최근 10건을 보여준다. 펼치면 요청 의도·선택한 자료의 이미지와 근거·등록 정보·비교 이미지 세 장·AI에 반환한 출력을 확인한다. 비교 보고서는 해당 호출의 보관 파일을 사용한다.

같은 작업은 `--task`로 연결한다. `brief`가 반환한 task ID를 후속 명령과 `nextActions`가 사용한다. 검색·등록·비교·실행 오류를 보관하며, `history`와 도움말 조회는 새 작업 기록을 만들지 않는다.

## 로컬 자료

`<store>/activity/<호출ID>/entry.json`에 출력과 이미지 목록을 저장한다. PNG와 정적 비교 보고서는 같은 폴더에 보관한다. 숨긴 임시 폴더에 작성한 뒤 한 번에 발행하므로 브라우저는 발행된 기록만 읽는다. 화면은 최근 10건을 표시하고 이전 근거 파일도 보관한다.

CLI와 웹은 같은 store를 사용한다. 기본값은 현재 폴더의 `.design-compare`다. 지정할 때 CLI는 `--store` 또는 `DESIGN_STORE`, 웹은 `DESIGN_STORE`를 사용한다.

웹은 `/api/activity`에서 최근 기록을, `/api/activity/<ID>`에서 해당 출력을, `/api/activity/<ID>/files/<파일명>`에서 목록에 있는 근거 파일을 읽는다. 웹 새로고침은 CLI 기록을 추가하지 않는다.
