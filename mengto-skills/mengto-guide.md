# Design Library — MengTo/Skills (참조용, 설치 안 함)

> **BLUF**: 이 폴더(`mengto-skills/`)는 MengTo의 디자인 스킬 95개를 **참조 라이브러리**로 clone해 둔 것이다.
> `~/.claude/skills`에 **설치하지 않는다** — 설치하면 스킬 목록이 상시 컨텍스트에 로드돼 토큰이 낭비되고,
> 기존 `impeccable`·`design-taste-frontend`·`design-an-interface`와 트리거가 경합한다.

## 유의점 (이 레포 접근 규칙)
- **설치 금지**: `npx skills add MengTo/Skills` 하지 말 것. 상시 스킬 목록 오염 + 충돌.
- **쓰는 법**: 디자인 작업 시 아래 인덱스를 훑고, 필요한 스킬의 `mengto-skills/agent-skills/<카테고리>/<스킬>/SKILL.md`를 **그때 열어** 지침으로 사용.
- **중복 주의**: `ui/` 의 취향·품질 스킬(high-end-visual-design, frontend-design, gpt-taste, redesign-existing-projects, design-taste-frontend, design-first-ui-prompting)은 기존 **impeccable / design-an-interface 와 역할이 겹친다.** 비평·감사는 기본적으로 impeccable 을 쓰고, MengTo ui 는 의도적으로 필요할 때만.
- **고유 가치**: `web-design/` 62개는 비주얼 프리셋(CSS/WebGL/GSAP/three.js)이라 기존 스킬과 직교 — 겹침 없음. 이 라이브러리의 핵심.
- **업데이트**: `cd design-library/mengto-skills && git pull`
- clone 폴더는 `.gitignore` 처리됨(jeongcheoki 히스토리에 vendoring 안 함). 이 README 만 커밋.
