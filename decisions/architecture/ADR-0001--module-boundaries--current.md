# ADR-0001 · 모듈 경계

관심사: ARCH-001. 적용: MOD-001.

맥락: 학습 화면과 검토 도구가 한 저장소에서 실행된다. 화면 분리만으로는 규칙 중복과 역방향 의존을 막지 못한다.

선택: 단일 배포를 유지하고 학습(용어집·패턴), 검토(Application·Library·Capture·Audit), 공통 표시 자원을 책임별로 둔다. Domain은 순수 계약을 소유하고 외부 모듈을 참조하지 않는다. 상위 조립은 공개 진입점으로 연결한다. 기존 호출 경로는 호환 Facade로 보존한다.

대안과 비용: 서비스 분리는 배포·통신 비용이 현재 요구보다 크다. 범용 이벤트 버스와 상속 계층은 흐름 추적을 어렵게 한다. 작은 Factory·Strategy와 함수 주입을 선택하며, 공유 코드는 같은 규칙일 때만 추출한다. 파일 수는 늘지만 변경 이유와 수명주기가 명확해진다.

결과: 데이터 형식·URL·DOM 접근성·모션 동작을 유지한다. 정적 의존성 검증과 실제 Chromium 조작을 함께 사용한다.
